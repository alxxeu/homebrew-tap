# Homebrew tap for Thoughts

[Thoughts](https://github.com/alxxeu/Thoughts) — a free-form canvas for scattered ideas, for macOS 14 or later.

```bash
brew install alxxeu/tap/thoughts
```

Thoughts updates itself (Sparkle), so `brew upgrade` leaves it alone. Thoughts is also on the [Mac App Store](https://apps.apple.com/app/id6809164763) — install one or the other, not both.
